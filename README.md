# ci-cd-final-project

## Project Overview

The `ci-cd-final-project` is a Counter REST API project developed to demonstrate Continuous Integration and Continuous Delivery (CI/CD) practices.

The project uses automated testing, code quality checks, and CI/CD workflows to help ensure that the application is reliable and maintainable.

## Project Details

- **Project name:** ci-cd-final-project
- **Project type:** Counter REST API
- **Primary focus:** Continuous Integration and Continuous Delivery (CI/CD)
- **Programming language:** Python

## Features

- REST API endpoints for counter operations.
- Automated testing to verify application functionality.
- Code quality checks and test automation.
- CI/CD workflow integration.
- Improved application reliability through continuous testing.

## Installation

Clone the repository:

```bash
git clone https://github.com/Shreyaslad99/ci-cd-final-project.git
cd ci-cd-final-project
```

Install the project dependencies:

```bash
pip install -r requirements.txt
```

## Running Tests

Run the project's tests using:

```bash
pytest
```

If the project specifies a different test command, use the command documented in its configuration.

## Continuous Integration and Delivery

The project demonstrates CI/CD principles by automating development checks and testing. These practices help identify problems early and support reliable software delivery.
